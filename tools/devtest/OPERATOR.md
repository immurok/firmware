# devtest 操作手册（给坐在设备旁边的人）

`README.md` 是参数和阶段的参考，这份是按流程走的手册：跑之前准备什么、每一段会让你做什么、
卡住了怎么救、跑完怎么收尾。全程大约 2 小时（不含 `--long` 的锁屏 30 分钟和 OTA 断电）。

## 0. 跑之前

准备好这些再开始：

- 设备：已配对到这台 Mac、电量 > 50%（P0 会检查，低于 3.5V 只警告）、至少登记了 1 根认证指纹。
- 手指：一根**已登记**的、一根**没登记**的（P3-02、P3-11、P4 要用）。P4-05 要再来一根用于重复登记测试。
- 一个能看到设备 LED 的位置，按键和 SW2 电源开关能摸到。
- 可选：USB 数据线 + release-debug 固件（`ota/upload-ota.sh release-debug`），这样 runner 能抓设备日志判复位。没有也能跑。
- P8 要一份当前版本的 `.imfw`（`firmware/dist/` 或 `firmware/build/immurok_CH592F.imfw`）。
- P6 要第二台装了 immurok 的电脑；没有就整段 SKIP，不影响别的阶段。

装测试钩子构建（会弹一次指纹授权，触摸即可）：

```bash
cd app-macos && ./build-deploy.sh -a -t && ./build-deploy.sh --agent
```

不要用 `-s` 在没有终端的地方跑（比如 agent 的 `!` 命令）：它要 sudo 密码，
拿不到密码但已经把 App 杀掉了，得先 `open /Applications/immurok.app` 再用 `--agent` 补装。

装好后确认：

```bash
printf 'TEST:PING\n' | nc -U ~/.immurok/cli.sock     # 应回 OK:TEST_HOOKS <版本>
```

注意：测试构建开放了 `TEST:RAW`（任意字节写设备），只能装在开发机，测完必须换回普通构建（见第 4 节）。

## 1. 怎么跑

必须在一个真正的终端里跑（Terminal / iTerm），因为要读你敲的回车。在 agent 或管道里跑，
所有需要人的用例会显示 `SKIP 缺条件: human`。

```bash
cd firmware/tools/devtest
./devtest.py --phase p1 p2 --record            # 无人，约 3 分钟
./devtest.py --phase p3 p4 --record            # 指纹门 + 登记，约 20 分钟
./devtest.py --phase p5 --record               # 密钥库，约 10 分钟
./devtest.py --phase p6                        # 双机，需要第二台电脑
./devtest.py --phase p7                        # 连接，1 分钟；加 --long 多 35 分钟
./devtest.py --phase p8 --record --imfw <路径>  # OTA，约 15 分钟
./devtest.py --phase p9 --record               # 破坏性，逐项确认，约 20 分钟
```

每次开跑都会先过 P0（6 条前置检查），P0-05 会问三个问题：有没有第二台电脑、能不能拨 SW2、能不能开盖。
如实答，答"否"的相关用例会自动 SKIP。

终端里的提示分三种：

- `✋ 请触摸指纹传感器`：现在就做，不用回车。
- `▶ …（回车继续）[90s]`：做完动作再按回车。不按，90 秒后这条记 INVALID，接着跑下一条。
- `▶ … [y/N]`：y 回车或直接回车（等于 N）。破坏性用例会逐条这样问。

跑完最后一行是报告路径 `reports/<时间戳>.md`。中途 Ctrl+C 会把已跑完的部分写进报告，
之后 `--resume` 从断点继续（P0 会重跑，SKIP 过的条目会重试）。

## 2. 每一段会让你做什么

### P1、P2：不用管

P2 会往设备打畸形包，LED 可能闪几下，正常。这一段别碰传感器，
P2-18 那条需要你触摸一次产生一条真实匹配。

### P3 指纹门（12 条）

| 用例 | 你要做的 |
|---|---|
| P3-01 | 用已登记手指触摸一次 |
| P3-02 | 用**没登记**的手指连续触摸 3 次，看到第 3 次后停手 |
| P3-03 | 30 秒什么都别碰，等它超时；然后按提示再触摸一次 |
| P3-04 | 先别动，等提示"现在触摸一次"再摸 |
| P3-05 | 按 T1、T2、T3 三次提示各触摸一次，T2 紧跟 T1 |
| P3-06 | 触摸一次；再按提示做存活确认触摸 |
| P3-07 | 触摸一次 |
| P3-08 | 触摸一次，然后 8 秒内别碰 |
| P3-09 | **长按**传感器 3 秒松开。屏幕会锁，用已登记手指解锁后回到终端 |
| P3-10 | 用已登记手指触摸一次 |
| P3-11 | 用没登记的手指触摸一次 |
| P3-12 | 会跑一次真的 `sudo`，触摸一次 |

### P4 登记（8 条）

登记流程：先用已登记的手指触摸一次过门，然后换要登记的手指按提示反复按压、抬起，
终端会打印 `STEP:captured:n/6` 之类的进度，直到 `OK:COMPLETE`。

| 用例 | 你要做的 |
|---|---|
| P4-01 | 完整登记一根新手指（约 6 次按压） |
| P4-02 | 开始登记，按 2 次就停手，等它取消 |
| P4-03 | 开始登记，按 2 次就停手，runner 会断链，等它重连 |
| P4-04（--long） | 开始登记后 30 秒不按，等超时 |
| P4-05 | 用 P4-01 那根手指再登记一次到另一个槽；结束后按提示触摸一次删掉 |
| P4-06 | 不用管 |
| P4-07 | 触摸一次（删 P4-01 的槽），然后用**刚删掉的那根手指**触摸，预期不通过 |
| P4-08 | 用一根新手指登记到切换槽（槽 5），然后触摸它一次。已绑双机时这条自动 SKIP |

### P5 密钥库（6 条）

每次提示"需要门：触摸"就摸一下，每条 2 到 4 次。P5-03 中间有一句"接下来 12s 不要触摸"，
那 12 秒别碰。P5-06 会真的跑 `imk get`，要 App 里"imk CLI"开关是打开的，否则 SKIP。
写进设备的条目用例结束都会自己删掉，名字都以 `devtest`/`dt` 开头。

### P6 双机（5 条，需要第二台电脑）

| 用例 | 你要做的 |
|---|---|
| P6-01 | ① 触摸切换指纹（本机会断链）② 在第二台电脑的 App 里完成配对（触摸 + 按键）③ 再触摸切换指纹切回本机 ④ 回车 |
| P6-02 | 触摸切换指纹，看第二台电脑几秒连上，把秒数敲进终端 |
| P6-03 | 再触摸切换指纹切回本机 |
| P6-04 | 不用管 |
| P6-05 | 触摸一次（清另一槽）。**不要再碰切换指纹**，只看第二台电脑还能不能连，答 y/n |

### P7 连接

P7-01 不用管。P7-02（--long）按提示：关 Mac 蓝牙、等 90 秒、开蓝牙、触摸唤醒。
P7-03（--long）锁屏 30 分钟再回来。

### P8 OTA（7 条，需要 --imfw）

大部分不用管，每条 1 到 2 分钟，设备会重启一次、LED 会变。
P8-05 是断电测试：看到进度 50% 时立刻拨 SW2 断电，3 秒后拨回来，然后按回车。
任何一条之后设备超过 2 分钟没回来，看第 3 节。

### P9 破坏性（11 条）

进入 P9 前会单独确认一次。这一段会把设备**出厂重置好几次**，指纹、密钥、配对全部清空。
跑之前把密钥库导出备份。

| 用例 | 你要做的 |
|---|---|
| P9-02 | 不用管，设备会自己重置重启。App 会显示未配对，正常 |
| P9-03 | 设备白灯闪等按键时，**按住按键 1 到 3 秒松开**（别超过 3 秒，3 秒以上是出厂重置） |
| P9-04（--long） | 30 秒别按键，等超时 |
| P9-05 | 同 P9-03，按住 1 到 3 秒松开 |
| P9-06 | 先别按，3 秒后按提示短按一次 |
| P9-07 | 短按按键完成配对 |
| P9-08 | 有指纹时会提示触摸；重置后短按按键重配 |
| P9-09 | 长按按键 3 秒以上直到 LED 提示重置；重置后短按按键重配 |
| P9-10 | 设备需处于未配对。开盖，看红灯 1 秒亮 1 秒灭慢闪、蓝牙列表里消失，答 y/n；合盖 |
| P9-11 | 开盖，设备应断链、红灯常亮；合盖，拨 SW2 断电再上电 |
| P9-12 | 短按按键重配，然后回车结束 |

## 3. 卡住了怎么办

- **提示"请触摸"但设备没反应**：先看 LED。绿灯闪是在等你，没灯可能门已经超时（25 秒），
  这条会记 TIMEOUT，等下一条。
- **重置后设备 90 秒没回来**：终端会提示你到 系统设置 → 蓝牙 里"忘记"immurok 再连一次，
  做完回车，它再等 60 秒。
- **设备完全没反应**：短按一次按键，等 5 秒。还不行就拨 SW2 断电重启。
- **OTA 后不回来**：等满 2 分钟。仍不回来就是变砖了，用串口 ISP 刷回（`wchisp` 烧 Combined.hex，UART1 + BOOT 脚 PB22），这条记为固件问题。
- **登记到一半 App 弹了设置窗口**：关掉。测试期间不要开 App 的设置窗口，会顶掉登记回调。
- **终端里莫名多了一个空行、提示被自动跳过**：是 App 收到指纹匹配后"预发回车"打进了终端。
  runner 已在每次提问前清一次输入缓冲，若还发生就用 `--only <ID>` 单独重跑那条。
- **整轮提前结束，打印"设备 15s 没回来，中止本轮"**：设备掉线且用例没预期断链。
  确认设备回来后 `--resume`。

## 4. 跑完之后

1. 把 `reports/<时间戳>.md` 交给分析的人。FAIL 和 INVALID 的条目在"需要看的"一节，
   带体检 diff、事件总线切片、设备日志切片。
2. `--record` 跑过的阶段会更新 `baseline.json`，提交它：
   `git add firmware/tools/devtest/baseline.json`。
3. P9 跑过的话，在 App 里重新登记指纹、恢复密钥。
4. 换回普通构建：

```bash
cd app-macos && ./build-deploy.sh -a && ./build-deploy.sh --agent
printf 'TEST:PING\n' | nc -U ~/.immurok/cli.sock     # 应回 ERROR:UNKNOWN_COMMAND
```
